## 双向 CN2 GIA 到底指什么？59.43 和 202.97 一眼分清

CN2 是中国电信的下一代承载网，分 GT 和 GIA 两档。GT 通常只有国际出口那一段走 CN2 优化节点，数据进入国内后回到 163 骨干网，晚高峰 163 一堵，体验就参差不齐。GIA 是去程和回程全程都在 CN2 专属通道里跑，不经过普通骨干网，这就是“双向 CN2”，也叫“双程 CN2 GIA”。

判断方法不复杂：登录 VPS，跑一次回程路由，看节点 IP。

- 回程全程 `59.43.x.x`（AS4809）→ 真双向 CN2 GIA
- 国际出口后出现 `202.97.x.x` 或 `202.106.x.x` → CN2 GT，单程
- 全程 `202.97.x.x` → 普通 163 骨干网，没有 CN2

用 NextTrace 测三条回程最直观：

bash
# 安装
curl nxtrace.org/nt | bash

# 电信回程
nexttrace 219.141.136.10

# 联通回程
nexttrace 202.106.0.20

# 移动回程
nexttrace 221.179.155.161


三条结果里回程全段都是 `59.43.x.x`，才是真双向 GIA。商家页面只写“CN2”不注明 GT 还是 GIA 的，大概率是 GT；写着“双向 CN2”但回程出现 202.97 的，也不算数。

GIA 也有代价：出口带宽相对较小，遇到常见攻击容易波及整个 GIA 网络，费用比 GT 贵。它解决的是晚高峰绕路和拥堵，不是无限带宽。把 GIA 当成“一定比 GT 快”会失望，它的优势在全程走 CN2、晚高峰更稳。

## 常见问题

**双向 CN2 GIA 和 CN2 GT 区别在哪？**
GT 通常只有国际出口段走 CN2，进国内回 163 骨干网，晚高峰容易堵；GIA 去程回程全程走 CN2。判断看回程是否全程 `59.43.x.x`。

**怎么测是不是真 GIA？**
VPS 上跑 NextTrace 或 mtr，分别测电信 `219.141.136.10`、联通 `202.106.0.20`、移动 `221.179.155.161`。回程全段 59.43 就是真双向 GIA，出现 202.97 就不是。

**移动用户能用吗？**
按测评口径，三网回程都走 CN2 GIA，移动去程是直连。移动用户回程有 GIA，去程不如电信联通优化得彻底。下单前用测试 IP `45.9.10.70` 或 `45.9.10.146` 自己 ping 一下。

**年付能不能退款？**
资料显示商家标注不支持退款，且谢绝以非原生 IP 为由申请退款。没有看到免费试用或退款期限。年付前先月付试一个月更稳。

**800GB 双向流量够不够？**
上传加下载都算。个人博客、轻量代理通常够；每天下载超过 25GB 就要算一下，超了选 B1 mini 的 1.2TB 更稳。

**U 系列不限流量为什么只有 30Mbps？**
不限流量是用带宽换的。U1 30Mbps、U2 50Mbps、U3 100Mbps、U4 200Mbps。适合长跑备份、镜像同步，不适合建站和多人代理。
